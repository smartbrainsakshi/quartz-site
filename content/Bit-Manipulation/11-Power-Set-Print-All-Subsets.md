# Power Set (Print All Subsets)

## 🎯 What problem are we solving?

> [!question]
> Given an array `nums` of `n` distinct elements, print all possible subsets (the power set) — including the empty subset and the full array itself. (This also has a recursive solution, covered separately in the recursion section — this note covers the **bitmasking** approach.)

## 💡 Intuition

> [!tip]
> There are always exactly `2^n` subsets of an `n`-element set — the same as `1 << n` in bit terms. Each subset can be represented as an **n-bit binary mask**, where bit `i` being `1` means "include `nums[i]`" and bit `i` being `0` means "exclude it." Since every number from `0` to `2^n - 1` is a distinct `n`-bit pattern, **iterating that whole range and reading off which bits are set generates every possible subset exactly once** — no recursion, no explicit branching needed.

## 🖼️ Visualizing it

```
nums = [1, 2, 3], n = 3, so masks range from 0 to 2^3-1 = 7

mask=0 (000): include none          -> []
mask=1 (001): include index 0       -> [1]
mask=2 (010): include index 1       -> [2]
mask=3 (011): include indices 0,1   -> [1,2]
mask=4 (100): include index 2       -> [3]
mask=5 (101): include indices 0,2   -> [1,3]
mask=6 (110): include indices 1,2   -> [2,3]
mask=7 (111): include all           -> [1,2,3]
```

All 8 (`2^3`) subsets, each generated by checking which of the 3 bit positions are set in `mask`.

## 🛠️ Algorithm / Approach

> [!abstract]
> 1. Let `n = nums.length`. The number of subsets is `1 << n`.
> 2. For every `mask` from `0` to `(1 << n) - 1`:
>    - Build an empty subset list.
>    - For each bit position `i` from `0` to `n - 1`: if `mask & (1 << i)` is non-zero, add `nums[i]` to the subset.
>    - Add the completed subset to the answer list.
> 3. Return the answer list.

## 👨‍💻 Code

### Java

```java
import java.util.*;

public class PowerSet {

    public List<List<Integer>> subsets(int[] nums) {
        int n = nums.length;
        int totalSubsets = 1 << n;
        List<List<Integer>> answer = new ArrayList<>();

        for (int mask = 0; mask < totalSubsets; mask++) {
            List<Integer> subset = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    subset.add(nums[i]);
                }
            }
            answer.add(subset);
        }
        return answer;
    }
}
```

### Python

```python
def subsets(nums: list[int]) -> list[list[int]]:
    n = len(nums)
    total_subsets = 1 << n
    answer = []

    for mask in range(total_subsets):
        subset = [nums[i] for i in range(n) if mask & (1 << i)]
        answer.append(subset)

    return answer
```

## ⏱️ Complexity Analysis

> [!note]
> - **Time:** O(N × 2^N) — `2^N` masks, each requiring an O(N) inner scan to build its subset.
> - **Space:** O(N × 2^N) — hard to give an exact tighter bound since subset sizes vary, but this is a safe upper bound for the total output size across all subsets.

## ⚠️ Common Pitfalls

> [!warning]
> - **Forgetting the empty subset (`mask = 0`) or the full-set subset (`mask = 2^n - 1`).** Both are valid members of the power set and must be included — the loop bounds `0` to `2^n - 1` inclusive naturally cover both, but it's easy to accidentally off-by-one this.
> - **Assuming subset order matters.** It generally doesn't for this problem — mask-order and recursive-order can produce the subsets in different sequences, both valid.
> - **Reaching for the recursive/backtracking solution by default without considering bitmasking.** For a fixed, modest `n`, the iterative bitmask approach avoids recursion overhead entirely and is often simpler to reason about.
